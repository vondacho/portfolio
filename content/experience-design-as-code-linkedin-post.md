# Experience Design as Code

How do UX designers connect to an AI-driven, contract-driven SDLC?

By making experience intent part of the same specification backbone as domain behaviour, stories, examples, architecture, and code.

UX already contributes essential material: research evidence, user needs, journeys, touchpoints, flows, prototypes, content, accessibility requirements, and design-system decisions.

The problem is the handoff. Much of that meaning becomes a screenshot, a design link, or a paragraph copied into a ticket.

Experience Design as Code preserves the connections.

The user journey becomes the shared entry point. A service blueprint connects the frontstage experience to backstage processes, domain events, policies, systems, and teams.

From there:

- UX and product shape the Story Map backbone
- Pivotal events connect the journey to Event Storming
- User flows and prototype revisions remain linked to stories
- Interaction states become examples and acceptance evidence
- Design-system components and accessibility rules constrain implementation
- Production evidence reconnects to the original experience hypothesis

Figma can remain the visual working environment. Git holds the accepted experience contract that delivery depends on: stable identifiers, approved revisions, interaction states, content intent, accessibility rules, component versions, and links to the other lifecycle models.

AI can then help synthesise research, propose journeys and service blueprints, expose missing states, generate content or flow alternatives, and check design-system consistency.

People retain authority. UX owns user evidence and intended experience. Product owns outcomes and release choices. Domain and engineering own business and system behaviour. QA turns the connected contract into evidence.

GitOps-style automation keeps the pieces aligned without letting runtime data or generated output silently redefine the intended experience.

As-Code makes experience intent machine-readable. That lets AI boost UX work while connecting it directly to delivery.
